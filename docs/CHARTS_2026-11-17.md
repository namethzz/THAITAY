# กราฟข้อมูลราคา — 17 พ.ย. 2569

Branch: `feat/price-data-charts` งานรอบนี้แก้เฉพาะ frontend และข้อมูลสำหรับกราฟ ไม่ฝึก เปลี่ยน หรือทดลองโมเดล ML เพิ่ม

## สิ่งที่เพิ่ม

1. หน้าวัสดุ: เลือกประวัติราคาจริง 6/12/24 เดือน เปิด–ปิดเส้นประคาดการณ์เดิม และเปิดตารางราคา/เปอร์เซ็นต์เปลี่ยนจากเดือนก่อน ช่องว่างของราคาจริงเป็น null และไม่ลากเส้นข้าม
2. หน้าแรก: แท่งขึ้น–ลงสูงสุดหมวดละ 5 รายการ กรองหมวดได้ เทียบเฉพาะเดือนล่าสุดกับเดือนก่อนหน้าโดยตรงเป็นเปอร์เซ็นต์ แกนแท่งรวมศูนย์เสมอ ไม่เฉลี่ยราคาที่หน่วยต่างกัน
3. หน้าแรก: เปรียบเทียบแนวโน้ม 2–5 วัสดุ ช่วง 6/12/24 เดือน โดยใช้เดือนฐานที่มีราคาจริงร่วมกันทุกเส้นเป็น 100 พร้อมตารางข้อมูล สี รูปแบบเส้น และ tooltip ชื่อวัสดุ
4. ใบประมาณราคา: แท่งต้นทุนแต่ละวัสดุ ราคา × จำนวน พร้อมสัดส่วนของค่าวัสดุทั้งหมด ไม่รวม VAT/เงินสำรอง รวมกลุ่มรายการของวัสดุเดียวกัน และหากเกิน 12 กลุ่มแสดง 11 กลุ่มแรกกับยอดอื่น ๆ ที่รวมแล้วตรงยอดเดิม

## ข้อมูล

ไฟล์สำหรับกราฟ `frontend/public/data/chart-history.json` สร้างจากราคาจริงที่มีอยู่ใน `ml/api_data/prices.csv` และรายชื่อ active ของ frontend มีวันข้อมูล หน่วย และ SHA256 ของต้นทาง

ข้อมูลปัจจุบันครอบคลุม พ.ย. 2567–ต.ค. 2569 รวม 24 เดือน; 183 วัสดุ active และเปรียบเทียบ ก.ย.–ต.ค. ได้ 177 รายการ อีก 6 รายการข้อมูลไม่ครบ ราคาขึ้น 66 ลง 1 และเท่าเดิม 110 รายการ

`npm run dev` และ `npm run build` สร้างข้อมูลกราฟให้อัตโนมัติก่อนทำงาน ใช้ไฟล์ราคาที่มีใน repository ไม่เรียกบริการ ML หรือแหล่งข้อมูลภายนอกเพิ่ม รันแยกได้ด้วย `npm --prefix frontend run charts:data` จาก root

ไฟล์สำหรับกราฟเก็บเพียง 24 เดือน ไม่เพิ่มตัวเลือกที่เกินข้อมูล ไม่มีการเติม missing price หรือสร้าง confidence interval ใหม่ หากราคาตั้งต้นของ forecast ไม่ตรงเดือน/ค่าราคาของประวัติ จะไม่ต่อเส้นคาดการณ์เข้ากราฟ

## การตรวจสอบ

- `npm --prefix frontend run test:charts`: ผ่าน 8 ข้อ — calendar gaps, month adjacency/unit, common index base, missing index, cost subtotal, grouping without losing totals, 24-month export และตัวเลขจริง
- `npm --prefix frontend run build`: TypeScript และ production build ผ่าน
- Browser: กรองคอนกรีตพบราคาเท่าเดิม 9/9 รายการ; เปรียบเทียบ 3 วัสดุ 24 เดือนพบเดือนฐานทุกเส้นเป็น 100; จำกัดได้ 5 วัสดุ; ประวัติ SD40 มี 24 แถวและเปิด–ปิด forecast ได้
- ใบประมาณ: เปลี่ยนจำนวน 1→2 ทำให้กราฟค่าวัสดุ 175→350 บาท ส่วนยอดรวม VAT เป็น 187.25→374.50 บาท แล้วคืนจำนวนเดิมหลังตรวจ
- ตรวจหน้าประวัติ ใบประมาณ และหน้าแรกที่ viewport 390 px ไม่มี document overflow แนวนอน ตารางกว้างเลื่อนภายในกล่องได้
- ไม่พบ console error/warning ระหว่างการตรวจรอบสุดท้าย
