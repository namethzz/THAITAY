## หลัง v0.10: ราคาจริง ราคาคาดการณ์ และอัปเดตรายเดือน (ต.ค.–พ.ย. 2569)

- หน้าเว็บแสดงราคาจริงจาก สนค. แทนข้อมูลตัวอย่าง
- ราคาคาดการณ์ 1–3 เดือนใช้ Naive (ราคาเดือนหน้า = ราคาล่าสุด) เพราะทดลอง 16 แบบแล้วไม่มีแบบไหนชนะได้ทั้งช่วงทดสอบย้อนหลังและ 12 เดือนล่าสุด
- ช่วงราคาต่ำ–สูงคิดจากการเปลี่ยนแปลงราคาจริงในอดีตของแต่ละหมวด (`ml/bands.py`) ครอบราคาจริง 87/87/83% ในช่วงทดสอบ
- ป้าย "ราคามีโอกาสเปลี่ยน" ใช้ LightGBM ขึ้นป้ายเมื่อโอกาส 70% ขึ้นไป ขึ้นป้ายแล้วราคาเปลี่ยนจริง 80%
- วัสดุที่ สนค. เลิกเก็บราคาแสดงว่า "ไม่มีราคาล่าสุด"
- ข้อมูลราคาเป็นไฟล์ JSON ในเว็บ (`frontend/public/data/prices/`) Vercel ส่งไปพร้อมหน้าเว็บ ไม่ต้องมี backend
- `ml/monthly_update.sh` อัปเดตราคาเดือนใหม่ครบทุกขั้นในคำสั่งเดียว รวมดึงปัจจัยภายนอกเอง (`ml/fetch_factors.py`) และสอบคำทายเดือนก่อนกับราคาจริง (`ml/live_check.py`)

## v0.10: icon หมวด, ราคาต่อเส้น, ใบประมาณที่ส่งต่อได้, ติดตามวัสดุ

ต่อจาก v0.9 (ค้นหาแล้วเห็นราคาทันที) เพิ่ม 4 อย่างที่เจ้าของเลือก โดยไม่เพิ่มตัวเลือกในจอแรก

### icon หมวดวัสดุ
- ใช้ชุด icon 9 หมวดที่เจ้าของส่งมา ตัดเป็นไฟล์ละหมวดที่ `frontend/public/icons/categories/STR-01.webp` … `STR-09.webp` เอาพื้นดำเดิมออก (พื้นโปร่งใส) แล้ววางบนแผ่นสีอ่อนของแบรนด์ด้วย CSS ไฟล์ละไม่เกิน 25 KB
- หน้าแรกมีส่วน "เลือกดูตามหมวด" สำหรับคนที่ไม่รู้จะพิมพ์อะไร กดแล้วเปิดรายการทั้งหมวด
- icon อยู่ในชิปหมวด แถวผลค้นหา รายการในช่องค้นหา หัวหน้าวัสดุ ป้ายหมวดบนการ์ดราคา และรายการในใบประมาณ
- เปลี่ยน icon: วางไฟล์ใหม่ชื่อเดิมทับได้เลย (สัดส่วน 220×192 พื้นโปร่งใส)

### ราคาต่อเส้น (เหล็กเส้น)
- เหล็กเส้นขายเป็นตัน แต่หน้างานนับเป็นเส้น: การ์ดราคาแสดง "≈ ฿214 ต่อเส้น · ยาว 10 ม. หนัก 8.88 กก." คำนวณจากน้ำหนักมาตรฐาน 0.00617 × ศก.² กก./ม. และความยาวในชื่อสินค้า
- กล่องคำนวณต้นทุนเลือก "สั่งเป็น เส้น / ตัน" ได้ (ค่าเริ่มต้นเป็นเส้น) และบอกว่าเท่ากับกี่ตัน
- รายการที่สั่งเป็นเส้นเข้าใบประมาณเป็นหน่วย "เส้น" พร้อมราคาต่อเส้น

### ใบประมาณราคาที่ส่งต่อได้
- ใส่ชื่อโครงการและลูกค้าได้ เว็บจำไว้พร้อมเงินสำรองและ VAT (เปิดใหม่ยังอยู่)
- "พิมพ์ / PDF": กระดาษหน้าตาเป็นใบเสนอราคา (หัว THAI TAY, โครงการ, ลูกค้า, วันที่, ตารางรายการ, ยอดรวม, หมายเหตุ) เลือก "บันทึกเป็น PDF" ในหน้าพิมพ์ได้
- "ส่งทาง LINE" และ "คัดลอกลิงก์": ลิงก์เก็บรายการและราคา ณ วันที่ส่งไว้ในตัว ไม่ต้องมีเซิร์ฟเวอร์ คนเปิดลิงก์เห็นใบเดียวกันแบบอ่านอย่างเดียว พร้อมปุ่ม "บันทึกเป็นใบของฉัน" ใบประมาณของคนเปิดเองไม่ถูกแตะจนกว่าจะกดปุ่มนี้
- ลิงก์ที่ไม่ครบหรือเสียจะบอกให้ขอลิงก์ใหม่ แทนที่จะแสดงหน้าว่าง

### ติดตามวัสดุ ★
- ปุ่ม "ติดตาม" บนการ์ดราคา (หน้าแรกและหน้าวัสดุ)
- หน้าแรกแสดง "วัสดุที่ติดตาม" พร้อมราคาล่าสุดและการเปลี่ยนแปลงใน 3 เดือน เฉพาะเมื่อมีวัสดุที่ติดตามแล้ว คนที่เข้ามาครั้งแรกไม่เห็นอะไรเพิ่ม
- กดติดตามจากหน้าอื่นจะมีแจ้งเตือนพร้อมลิงก์ไปหน้าแรก

### ข้อมูลที่เว็บจำไว้ในเบราว์เซอร์
| key | เก็บอะไร |

| `thai-tay-estimate-v1` | รายการในใบประมาณ |
| `thai-tay-estimate-meta-v1` | ชื่อโครงการ ลูกค้า เงินสำรอง VAT |

เก็บเฉพาะในเครื่องของผู้ใช้ ไม่ส่งไปที่ไหน ถ้าเบราว์เซอร์บันทึกไม่ได้ (เช่น private mode) เว็บยังใช้งานได้ตามปกติ แค่ไม่จำ

### ปรับหลัง merge: ตัวกรองในหน้าค้นหา
- ปุ่ม "ตัวกรอง" ข้างปุ่มหมวด (มือถือเหลือเป็น icon พร้อมตัวเลขจำนวนตัวกรองที่เปิด) กดแล้วเปิดแผง:
  - เรียงตาม: แนะนำ / ราคาลงมากสุด / ราคาขึ้นมากสุด / ราคาต่ำ → สูง / สูง → ต่ำ (เรียงราคาจะจัดกลุ่มตามหน่วยก่อน เพราะราคาต่างหน่วยเทียบกันไม่ได้)
  - แนวโน้มราคา 3 เดือน: ราคาลง / ทรงตัว / ราคาขึ้น (เกณฑ์ ±1% แบบเดียวกับคำแนะนำบนการ์ดราคา)
  - หน่วยที่ขาย: แสดงเฉพาะหน่วยที่มีในผลค้นหา

- เลือกแล้วผลเปลี่ยนทันที ปุ่มด้านล่างบอกจำนวนผลลัพธ์ และมี "ล้างทั้งหมด"

- ตัวกรองเก็บใน URL (`sort`, `trend`, `unit`, `grade`, `size`) กดเข้าหน้าวัสดุแล้วย้อนกลับ ตัวกรองยังอยู่ และส่งลิงก์ให้คนอื่นเห็นผลเดียวกันได้
- ถ้าตัวกรองทำให้ไม่เหลือรายการ หน้าจะบอกและมีปุ่มล้างตัวกรอง
- การกรองตามแนวโน้มและการเรียงต้องใช้ราคาทุกรายการที่ตรงคำค้น (โหลดผ่านแคชเดียวกับการ์ดราคา) เมื่อต่อ API จริงควรมี endpoint ราคาหลายรายการในครั้งเดียว

## v0.9: ออกแบบใหม่ ค้นหาแล้วเห็นราคาทันที

ทำตามความเห็นต่อ v0.8 ว่า "ไม่รู้ว่าเว็บต้องการสื่ออะไร ใช้งานงง ต้องเลือกเยอะ" และตามสไตล์งานของเจ้าของ (AirClean, KickHub) โลโก้และสีแบรนด์ THAI TAY CONSTRUCT เหมือนเดิม

### ใจความของเว็บ
- หัวข้อใหญ่กลางจอ: **"รู้ราคาวัสดุก่อสร้าง ล่วงหน้า 3 เดือน"** บอกทันทีว่าเว็บทำอะไร
- งานหลักงานเดียว: พิมพ์ชื่อวัสดุในช่องค้นหาใหญ่ แล้วรายการขึ้นพร้อมราคาเลย เลือกแล้วการ์ดราคาด้านล่างเปลี่ยนทันที (ราคาล่าสุดตัวใหญ่ + อีก 1, 2, 3 เดือน + คำแนะนำหนึ่งบรรทัดว่าควรซื้อตอนนี้หรือรอ)
- พิมพ์แบบคนหน้างานก็เจอ: "sd40" เจอ "SD.40", "DB12" เจอเหล็กข้ออ้อย 12 มม., "RB9" เจอเหล็กกลม 9 มม., "4 หุน" เจอขนาด 12 มม., "ปูน" เจอคอนกรีตผสมเสร็จ, "ไวร์เมช" เจอตะแกรงเหล็ก, "เอชบีม" เจอ H-Beam ถ้าไม่มีวัสดุที่พิมพ์ (เช่น ปูนซีเมนต์) จะบอกว่าตอนนี้มีหมวดไหนบ้าง พร้อมคำให้กด
- ชื่อสั้นอ่านง่าย: รายการขึ้นต้นด้วยสเปกที่ต่างกัน เช่น "เหล็กข้ออ้อย SD40 · 16 มม." ส่วนชื่อเต็มตามกระทรวงพาณิชย์อยู่บรรทัดรอง (เหล็กเส้น ตะแกรง ลวดอัดแรง คอนกรีตผสมเสร็จ)

### เหลือ 3 หน้า
| หน้า | hash | มีอะไร |
|---|---|---|
| หน้าแรก | `#home` | หัวข้อ ช่องค้นหา ปุ่มลัด 5 วัสดุ การ์ดราคาบนภาพหน้างาน วิธีใช้ 3 ขั้นตอน ที่มาของราคา |
| ค้นหาวัสดุ | `#search` | ช่องค้นหา ชิปหมวด รายการพร้อมราคา กดรายการแล้วเปิดหน้าวัสดุ (`#m/<รหัส>`) |
| ใบประมาณราคา | `#estimate` | รายการที่เพิ่มไว้ ปรับจำนวน เงินสำรอง VAT 7% ยอดรวม ช่วงต่ำ–สูง CSV และพิมพ์ |

หน้าวัสดุรวมทุกอย่างของวัสดุนั้นไว้ที่เดียว: ราคาล่าสุด ราคาคาดการณ์ 3 เดือนพร้อมช่วงต่ำ–สูง คำแนะนำ กราฟย้อนหลัง 12 เดือนต่อด้วยคาดการณ์ และกล่องคำนวณต้นทุน (สวิตช์ ตอนนี้ / 1 / 2 / 3 เดือน ใส่จำนวน เพิ่มลงใบประมาณ) ราคาแต่ละช่วงแสดงที่การ์ดราคาที่เดียว ไม่ซ้ำในกล่องคำนวณ แทนหน้าภาพรวม รายการวัสดุ วิเคราะห์ พยากรณ์ และคำนวณต้นทุนเดิม

ลิงก์เก่ายังเปิดได้: `#overview` → หน้าแรก, `#prices` → ค้นหา, `#forecast` / `#analysis` → หน้าวัสดุที่ดูล่าสุด, `#cost` → ใบประมาณราคา

### การใช้งาน
- มือถือ: แถบล่าง 3 ปุ่ม (หน้าแรก / ปุ่มค้นหาวงกลมส้มตรงกลาง / ใบประมาณ พร้อมตัวเลขจำนวนรายการ) จอใหญ่: เมนู 3 ลิงก์ด้านบน ไม่มี sidebar แล้ว
- ใบประมาณราคาจำไว้ในเครื่อง ปิดเปิดเว็บใหม่รายการยังอยู่
- จำนวนพิมพ์ทศนิยมได้ (เช่น 2.5 ตัน) มีปุ่ม − / +
- เพิ่มรายการแล้วมีแจ้งเตือนพร้อมลิงก์ไปใบประมาณ
- ใช้คีย์บอร์ดได้ทั้งหมด: ช่องค้นหาเลื่อนด้วยลูกศร Enter เลือก Esc ปิด

### หน้าตา
- พื้น Warm White การ์ดขาว มุมโค้งใหญ่ ปุ่มหลักสีส้มตัวหนังสือ charcoal ตัวเลขราคาใหญ่แบบ AirClean
- จอแรกเห็นราคาตัวอย่างเลยโดยไม่ต้องเลื่อน (ตรวจที่ 1440×900, 1366×768, 1024×768, 768×1024, 390×844)
- ราคาจริงสี charcoal ราคาคาดการณ์ส้มเข้ม แพงขึ้น/ถูกลงบอกด้วยคำและลูกศร ไม่ใช้สีอย่างเดียว
- ภาพใต้ช่องค้นหาตอนนี้เป็นภาพวาดหน้างาน (โครงเสา-คาน + ทาวเวอร์เครนยกเหล็กเส้น) รอรูปจริง

### ใส่รูปจริง
1. วางไฟล์ใน `frontend/public/photos/` เช่น `hero.jpg` (แนวนอน กว้าง 2000 px ขึ้นไป)
2. แก้ `frontend/src/config/photos.ts`: `hero: { file: "hero.jpg", alt: "คำอธิบายภาพ" }`
บนจอใหญ่การ์ดราคาวางทับซีกขวาของภาพ ให้ใช้ภาพที่จุดสนใจอยู่ซีกซ้าย

## v0.7: ออกแบบใหม่ทั้งเว็บ

ทิศทาง "ป้ายเหล็กเส้นจากโรงงาน" ที่เจ้าของเลือก ไม่มีสีดำ ชื่อแสดงเป็น **THAI TAY** ทุกที่

### หน้าแรก (`#home`)
- ทั้งหน้าคือป้ายมัดเหล็กสีเหลืองหนึ่งแผ่น แขวนด้วยลวดผ่านห่วงตาไก่
- บนป้ายมีช่องข้อมูลแบบป้ายโรงงาน: เลือกวัสดุได้ในช่อง "วัสดุ" แล้วรหัสสินค้า หน่วย ราคาล่าสุด และราคาคาดการณ์ 1/2/3 เดือนพร้อมช่วงต่ำ–สูงเปลี่ยนตามทันที
- กด "ตัวเลขนี้มาจากไหน?" เพื่อพลิกป้ายดูด้านหลัง: ที่มาของราคา วิธีพยากรณ์ (ระบุว่ายังพัฒนาอยู่) และเหตุผลที่ให้เป็นช่วงราคา ผู้ใช้ที่ตั้ง "ลดการเคลื่อนไหว" จะเห็นเป็นการเฟดแทนการหมุน
- ตราประทับ "ข้อมูลตัวอย่าง" บนป้ายตราบที่ยังไม่ได้เชื่อม backend
- ด้านล่างป้าย: ขั้นตอนใช้งาน 3 ขั้น, 9 หมวดวัสดุ (กดเข้ารายการที่กรองหมวดแล้ว), เหมาะกับใคร
- วัสดุที่เลือกบนป้ายตามไปทุกหน้าในพื้นที่ทำงาน

### พื้นที่ทำงาน
- สีใหม่ทั้งหมดจาก token ใน `src/styles/app.css`: พื้นสังกะสีอ่อน แผ่นป้ายสีขาว เหลืองป้ายสำหรับสิ่งที่เลือกและปุ่มหลัก ตัวอักษรน้ำเงินเข้ม ราคาจริงสีน้ำเงิน ราคาคาดการณ์สีบรอนซ์
- ฟอนต์ใหม่ Chakra Petch (หัวเรื่อง/ตัวเลข) + Bai Jamjuree (เนื้อหา) ตัวอักษรใหญ่ขึ้นทั้งเว็บ (เนื้อหา 15px)
- 9 หมวดวัสดุมีสีประจำแบบสีทาปลายมัดเหล็ก (`src/config/categoryPaint.ts`) ใช้คู่กับชื่อหมวดเสมอ
- ภาพรวม: เอา Hero ภาพตึกและกล่อง "รอข้อมูลราคา" (ล้าสมัย) ออก แทนด้วยแผงวัสดุที่กำลังดู + ราคาล่าสุด + คาดการณ์ 3 เดือน + ปุ่มไปต่อ
- รายการวัสดุ: ตัวกรองหมวดเป็นชิปแถวเดียว (มือถือเลื่อนแนวนอน) แทนการ์ด 10 ใบ และเอา dropdown หมวดที่ซ้ำออก
- พยากรณ์: ป้าย 1/2/3 เดือนกดเลือกช่วงที่แสดงในกราฟได้ (เอาแท็บที่ซ้ำออก) และแก้กราฟที่เส้นวาดไม่ครบ (ปิด animation)
- หน้าวิเคราะห์/พยากรณ์: เอากล่องรายละเอียดวัสดุที่ซ้ำกับตัวเลือกวัสดุออก
- เอาป้ายภาษาอังกฤษตัวเล็กเหนือหัวเรื่อง (STRUCTURAL MATERIAL CATALOG ฯลฯ) ออกทุกหน้า
- Sidebar: เอากล่องโปรโมตที่ซ้ำกับเมนูออก แสดงสถานะ "ราคาเป็นข้อมูลตัวอย่าง" แทน
- แถบบน: เอาวงกลม "เท" ที่ไม่มีหน้าที่ออก
- หน้าต้อนรับ "hello" เปลี่ยนเป็นธีมใหม่

### แก้จากการรีวิวงานออกแบบ
- ข้อมูลตัวอย่าง: ราคาเดือนเดียวกันตรงกันทุกหน้าและทุกช่วงเวลา (เดิมหน้าวิเคราะห์ได้ราคาล่าสุดต่างจากหน้าอื่น) และราคาคาดการณ์ต่อจากราคาล่าสุดจริง
- ป้ายหน้าแรกเป็นสีเรียบ ไม่มีเงานูนปลอม ห่วงตาไก่วาดเป็น SVG ราคาคาดการณ์บนป้ายใช้สีบรอนซ์เข้มที่อ่านได้บนพื้นเหลือง
- ด้านหลังป้ายแสดงเส้นทางราคาของวัสดุที่เลือก: ราคาจริง 3 เดือน → ราคาคาดการณ์ 3 เดือนพร้อมช่วง
- ตัวเลือกวัสดุแสดงชื่อ 2 บรรทัด (เห็นขนาด/ความยาว) และรหัส 16 หลักไม่ถูกตัด
- บนมือถือ ตราประทับ "ข้อมูลตัวอย่าง" อยู่ในจอเดียวกับราคาเสมอ และป้ายสูงตามด้านที่แสดงอยู่
- ไม่มีกล่องซ้อนกล่องในพื้นที่ทำงาน หน้าคำนวณต้นทุน: ฝั่งกรอกข้อมูลวางบนพื้น ใบประมาณราคาเป็นแผ่นเดียว
- รูห่วงตาไก่มีเฉพาะสิ่งที่เป็นป้ายจริง (ป้าย 1/2/3 เดือน ป้ายวัสดุ) กรอบทั่วไปไม่มี จะได้ไม่ดูเหมือนปุ่มกด

### เชื่อม backend
ทุกหน้าเรียกข้อมูลผ่าน `src/services/priceService.ts` ตอนนี้เป็น **ข้อมูลตัวอย่าง (Demo)** และมีแถบเตือนในหน้า
เมื่อพร้อม ตั้ง `VITE_API_BASE` (เช่น ในไฟล์ `.env`) แล้วทำ endpoint ตามนี้:

- `GET /prices/{materialId}/history?months=1..3` → `{ unit, points: [{ date, price }] }`
- `GET /prices/{materialId}/forecast?months=3` → `{ unit, points: [{ month, date, price, low, high }] }`

แถบ Demo จะหายเองเมื่อมี `VITE_API_BASE`
