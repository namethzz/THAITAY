# ตรวจเว็บบนขนาดจอมือถือ — 17 พ.ย. 2569

Branch: `fix/mobile-layout-audit`

ตรวจเว็บ local ด้วยเบราว์เซอร์ โดยจำลอง viewport ไม่ใช่การทดสอบเครื่อง iPhone/Android จริง

## สิ่งที่พบและแก้

1. กล่องข้อมูลกราฟยื่นพ้นการ์ดบนจอแคบ: จำกัดความกว้าง ตัดบรรทัดข้อความ และยึดไว้ด้านบนขวาของกราฟเมื่อจอกว้างไม่เกิน 960px
2. ชื่อวัสดุในผลค้นหาถูกบีบด้วยคอลัมน์ราคา: ย้ายราคาไปแถวถัดไปเมื่อจอไม่เกิน 400px
3. ช่องเพิ่มวัสดุเปรียบเทียบมีตัวอักษร 13px และพื้นที่รายการไม่เหมาะกับจอเตี้ย: ใช้ 16px เลื่อนช่องขึ้นเมื่อโฟกัส จำกัดความสูงรายการตาม viewport และขยายพื้นที่กดปุ่มล้าง/นำออก
4. ตัวกรองบนจอแนวนอน 844×390 ยื่นลงพ้นจอ: เปลี่ยนเป็นแผงที่อยู่ในจอ โดยหัวและปุ่มท้ายอยู่กับที่ รายการภายในเลื่อนได้
5. ยอดเงินหลักล้านในใบประมาณราคาทำให้ชื่อวัสดุแคบมากบนจอ 320px: แยกจำนวนและยอดเงินคนละแถวเมื่อจอไม่เกิน 400px
6. ใบประมาณราคาที่แชร์ซ่อนจำนวนวัสดุบนจอไม่เกิน 360px: จำกัดกฎซ่อนหน่วยให้ใช้เฉพาะใบที่แก้ไขได้ จำนวนและหน่วยในใบที่แชร์แสดงตามเดิม

- `npm run test:charts --prefix frontend`: ผ่าน 8 รายการ
