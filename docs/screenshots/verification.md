# ผลตรวจ THAI TAY Frontend v0.10

- `npm run build`: ผ่าน TypeScript และ Vite build
- Catalog: วัสดุโครงสร้าง 287 รายการใน 9 หมวด ไม่มีฟิลด์ราคาใน catalog (`frontend-catalog-results.json`)
- ทดสอบด้วย browser ที่จอ 1440 และ 390 (`frontend-ui-results.json`)
  - ฟีเจอร์ v0.10: 51/51 ข้อผ่าน
    - icon 9 หมวดโหลดครบ และการ์ดหมวดเปิดรายการที่กรองแล้ว (เหล็กเส้น 74 รายการ)
    - ราคาต่อเส้น = ราคาต่อตัน × น้ำหนักต่อเส้น (12 มม. = 8.88 กก.)
    - สั่ง 120 เส้นแล้วยอดรวมถูกต้อง สลับเป็นตันได้ และรายการเข้าใบประมาณเป็น "เส้น"
    - กดดาวติดตามแล้ววัสดุขึ้นที่หน้าแรก และยังอยู่หลังรีเฟรช
    - ชื่อโครงการยังอยู่หลังรีเฟรช
    - ลิงก์ LINE มีลิงก์ใบประมาณอยู่ข้างใน คนเปิดลิงก์ในเบราว์เซอร์อื่นเห็นยอดรวมเดียวกัน แบบอ่านอย่างเดียว พร้อมวันที่ของราคา
    - "บันทึกเป็นใบของฉัน" ใช้ได้ และรายการยังบอกวันที่ของราคาไว้
    - ลิงก์ที่ถูกแก้ให้ตัดป้ายข้อมูลตัวอย่างยังแสดงป้ายอยู่ ส่วนลิงก์เสียบอกให้ขอใหม่
    - ตอนพิมพ์เห็นเฉพาะใบเสนอราคา พร้อมกรอบ "ข้อมูลตัวอย่าง"
    - แจ้งเตือนบนจอใหญ่ไม่บังปุ่ม "เพิ่มลงใบประมาณราคา"
  - ชุดเดิมของ v0.9: 46/46 ข้อผ่าน
- จอแรกเห็นราคาตัวอย่างโดยไม่ต้องเลื่อนที่ 1440×900, 1366×768, 1024×768, 768×1024 และ 390×844
- ไม่มีส่วนไหนล้นขอบจอ ตรวจหน้าแรก ค้นหา หน้าวัสดุ 2 แบบ และใบประมาณ ที่ 320, 390, 768, 1024 และ 1440 px โดยวัดทุก element เทียบขอบจอ ซึ่งจับกรณีที่ถูก overflow ซ่อนไว้ได้ด้วย
- Browser ไม่พบ JS error และไม่มี request ไปบริการภายนอก ปุ่ม LINE เปิดเฉพาะเมื่อผู้ใช้กด
- ราคาทั้งหมดเป็นข้อมูลตัวอย่าง มีป้ายบนการ์ดราคา ในใบประมาณ บนกระดาษที่พิมพ์ และในลิงก์ที่ส่ง
- สีทุกคู่ที่เป็นตัวหนังสือผ่าน WCAG AA (≥ 4.5:1)
- ผู้ตรวจงานออกแบบอิสระ
  - รอบแรกให้ "fix" 9 ข้อ: การ์ดที่ 320 px, ป้ายข้อมูลตัวอย่างบนกระดาษ, ลิงก์ที่ตัดป้ายได้, ราคาจากลิงก์ที่ดูเหมือนราคาวันนี้, หัวการ์ดหน้าวัสดุที่ 320 px, ขนาด icon บนมือถือ, แจ้งเตือนบังปุ่ม, วันที่แบบ UTC และเลขเวอร์ชัน
  - แก้ครบ รอบสองให้ "ship" โดยไม่มีปัญหาใหม่
