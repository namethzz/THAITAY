# ผลตรวจ THAI เท Frontend v0.6

- `npm run build`: ผ่าน TypeScript และ Vite build
- Catalog: วัสดุโครงสร้าง 287 รายการใน 9 หมวด ไม่มีฟิลด์ราคาใน catalog (`frontend-catalog-results.json`)
- ข้อมูลราคาในหน้าวิเคราะห์ พยากรณ์ และคำนวณต้นทุนเป็นข้อมูลตัวอย่าง (Demo) จาก `priceService.ts` และมีแถบเตือนในหน้า
- ไม่เปิดหน้าล้นแนวนอนทุกหน้า (หน้าแรก ภาพรวม รายการวัสดุ วิเคราะห์ พยากรณ์ คำนวณต้นทุน) ที่ 1440, 1024, 768, 390 และ 320 px
- Browser ไม่พบ JS error และไม่มี request ไปบริการภายนอก
- หน้าแรก: เมนูไม่ทับกันทุกขนาดจอ เมนูมือถือเปิด/ปิดได้และปิดด้วย Esc ปุ่มและลิงก์ไปหน้าที่ถูกต้อง
- กดหมวดจากภาพรวมเปิดรายการวัสดุที่กรองหมวดนั้น
- วัสดุที่เลือกตามไปหน้าพยากรณ์ → วิเคราะห์ → คำนวณต้นทุน และรายการในใบประมาณราคาอยู่ครบเมื่อเปลี่ยนหน้า
- Sidebar มือถือเปิดได้และปิดด้วย Esc, กดโลโก้กลับหน้าแรก, hash ที่ไม่รู้จักเปิดหน้าภาพรวม
- CSS cleanup (ลบ declaration ที่ถูกทับและ rule ที่ไม่มี class ในโค้ด): ภาพหน้าจอ 33 ภาพ (6 หน้า × 5 ขนาดจอ + sidebar มือถือ) ก่อนและหลังแก้ตรงกันทุก pixel
