# ผลตรวจ THAI เท Frontend v0.5

- npm run build: ผ่าน TypeScript และ Vite build
- Catalog ใช้เฉพาะชื่อ รหัส หน่วย หมวด และ family code ของวัสดุโครงสร้าง 287 รายการใน 9 หมวด
- ตรวจรายการ ชื่อ หน่วย และหมวดตรงกับ metadata ของรายการ included และไม่รวม 5 รายการที่พักทบทวนขอบเขต
- ไม่มีราคา วันที่ราคา ประวัติราคา หรือ ML readiness อยู่ใน catalog ที่โหลดบนเว็บ
- ทดสอบเข้าถึงรายการผ่านหมวดและ pagination ได้ครบ 287 รายการ
- กดหมวดจาก Overview เปิดหน้า catalog ที่กรองหมวดนั้นถูกต้อง
- มุมมองทุกหมวดแบ่งหัวข้อชัดเจน ค้นหาชื่อ/รหัส กรองหมวด แบ่งหน้า เลือก และล้างตัวกรองได้
- ตัวเลือกวัสดุแสดงหน่วยแทนราคา รองรับค้นหาและเลือกด้วยคีย์บอร์ด
- วัสดุที่เลือกตามไปหน้าวิเคราะห์และพยากรณ์
- หน้าราคา/กราฟเป็น placeholder และหน้าพยากรณ์มีการ์ด 1/2/3 เดือน โดยไม่มีตัวเลขราคาหรือผลโมเดล
- ทุกหน้าเปิดที่ 1440, 768, 390 และ 320 px ไม่มี document overflow
- ตรวจ MaterialPicker บนจอ 320 px รวมเมนูมือถือ Escape และ browser Back: ผ่าน
- Browser ไม่พบ JS / HTTP error ไม่มี request ไปบริการภายนอก และไม่มี fetch / XHR เพื่อเรียก API
- ตรวจภาพ desktop, mobile และ catalog แล้ว

การตรวจนี้เป็นของ frontend และ catalog ไม่ใช่ผลฝึก/ประเมิน ML หรือ backend deployment

หลักฐานเพิ่มเติม: frontend-ui-results.json และ frontend-catalog-results.json
