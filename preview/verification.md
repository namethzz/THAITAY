# ผลตรวจ THAI TAY Frontend v0.8

- `npm run build`: ผ่าน TypeScript และ Vite build
- Catalog: วัสดุโครงสร้าง 287 รายการใน 9 หมวด ไม่มีฟิลด์ราคาใน catalog (`frontend-catalog-results.json`)
- ราคาในหน้าแรก ภาพรวม วิเคราะห์ พยากรณ์ และคำนวณต้นทุนเป็นข้อมูลตัวอย่าง (Demo) มีตราประทับ/แถบเตือนทุกหน้า
- ราคาเดือนเดียวกันของวัสดุเดียวกันตรงกันทุกหน้าและทุกช่วงเวลา (ตรวจ: หน้าแรก ภาพรวม วิเคราะห์ 3 เดือน / 1 ปี / 10 ปี ได้ค่าเดียวกัน) และราคาคาดการณ์ต่อจากราคาล่าสุด
- ไม่มีหน้าล้นแนวนอนทุกหน้าที่ 320, 390, 768, 1024, 1280 และ 1440 px
- Browser ไม่พบ JS error และไม่มี request ไปบริการภายนอก
- หน้าแรก: เลือกวัสดุบนป้ายแล้วตัวเลขเปลี่ยนตาม วัสดุที่เลือกตามไปหน้าพยากรณ์และคำนวณต้นทุน พลิกป้ายด้วยคีย์บอร์ดได้ (focus ย้ายไปด้านหลัง ด้านหน้าถูก inert) ตัวเลือกวัสดุบนมือถือเปิดเต็มจอ
- พื้นที่ทำงาน: ป้าย 1/2/3 เดือนเลือกช่วงในกราฟได้, การ์ดหมวดเปิดรายการที่กรองแล้ว, ชิป "ทุกหมวด" ล้างตัวกรอง, กดโลโก้กลับหน้าแรก, hash ที่ไม่รู้จักเปิดภาพรวม, sidebar มือถือปิดด้วย Esc
- สีทุกคู่ที่ใช้ผ่าน contrast WCAG AA (ตัวอักษรปกติ ≥ 4.5:1)
- ตัวตรวจจับปัญหาการออกแบบ (impeccable detect) ไม่พบปัญหา
- v0.7: รีวิวงานออกแบบโดยผู้ตรวจอิสระ 3 รอบ จบที่ "ship" (ขอบเขต: ข้อที่ให้คะแนน)
- v0.8 (โลโก้และสีแบรนด์): ผู้ตรวจอิสระให้ "fix" 7 ข้อ (Concrete Gray, ขอบช่องกรอก, เส้นคาดการณ์, สี "แพงขึ้น", ไอคอน, DESIGN.md, โลโก้บนหน้าต้อนรับ) รอบสองแก้ครบ 6 ข้อโดยไม่มีปัญหาใหม่ ข้อสุดท้ายคือเขียน DESIGN.md ใหม่ให้ตรงกับธีมแบรนด์
- โลโก้/ไอคอนจาก brand board ฝังที่มาไว้ในไฟล์ภาพทุกไฟล์ (impeccable embed-prompt --scan: 0 missing)
