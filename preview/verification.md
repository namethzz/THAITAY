# ผลตรวจ THAI TAY Frontend v0.9

- `npm run build`: ผ่าน TypeScript และ Vite build
- Catalog: วัสดุโครงสร้าง 287 รายการใน 9 หมวด ไม่มีฟิลด์ราคาใน catalog (`frontend-catalog-results.json`)
- ทดสอบการใช้งานจริงด้วย browser 46/46 ข้อผ่าน ทั้งจอ 1440 และ 390 (`frontend-ui-results.json`):
  - พิมพ์ "sd40" แล้วรายการขึ้นพร้อมราคา เลือกด้วยลูกศร + Enter แล้วการ์ดราคาเปลี่ยน และ focus ย้ายไปที่ชื่อวัสดุบนการ์ด
  - คำหน้างาน: "db12" และ "4 หุน" เจอเหล็ก 12 มม., "ปูน" เจอคอนกรีตผสมเสร็จ ส่วนคำที่ไม่มีในระบบ (ปูนซีเมนต์) จะบอกว่ามีหมวดไหนบ้าง
  - Enter เมื่อมีหลายรายการไปหน้าผลค้นหาทั้งหมด, ปุ่มลัดและปุ่มบนการ์ดเปิดหน้าวัสดุตัวเดียวกัน
  - หน้าวัสดุ: เลือก "3 เดือน" ใส่ 2.5 แล้วเพิ่มลงใบประมาณได้ มีแจ้งเตือนและตัวเลขบนเมนู ค้นหาวัสดุอื่นจากหน้าวัสดุได้
  - ใบประมาณราคาแสดงรายการที่เพิ่ม และยังอยู่หลังรีเฟรช
  - ลิงก์เก่า `#overview` `#prices` `#forecast` `#analysis` `#cost` และรหัสวัสดุที่ไม่มี เปิดหน้าที่ถูกต้อง
- จอแรกเห็นราคาตัวอย่างโดยไม่ต้องเลื่อนที่ 1440×900, 1366×768, 1024×768, 768×1024 และ 390×844 (บนมือถือไม่ถูกแถบล่างบัง)
- ไม่มีหน้าล้นแนวนอนทั้ง 4 หน้า ที่ 320, 390, 768, 1024 และ 1440 px
- Browser ไม่พบ JS error และไม่มี request ไปบริการภายนอก
- ราคาทั้งหมดเป็นข้อมูลตัวอย่าง (Demo) มีป้าย "ข้อมูลตัวอย่าง" บนการ์ดราคาทุกใบ ในใบประมาณราคา และหมายเหตุท้ายหน้า
- สีทุกคู่ที่เป็นตัวหนังสือผ่าน contrast WCAG AA (≥ 4.5:1) ขอบช่องกรอกผ่าน 3:1
- ผู้ตรวจงานออกแบบอิสระ: รอบแรก "fix" 6 ข้อ (คำค้นหน้างานและขอบเขต, ราคาในจอแรก + ตัด eyebrow, ราคาตัวอย่างไม่สมจริง, ราคาซ้ำในกล่องคำนวณ, รายการหน้าตาเหมือนกัน, สีกล่องคำแนะนำนอกแบรนด์) แก้ครบ รอบสอง "ship" ไม่มีปัญหาใหม่
