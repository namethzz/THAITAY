# THAI TAY

**รู้ราคาวัสดุก่อสร้างล่วงหน้า 3 เดือน**

พิมพ์ชื่อวัสดุงานโครงสร้าง เช่น เหล็กเส้น SD40 หรือคอนกรีตผสมเสร็จ แล้วเห็นราคาล่าสุดกับราคาคาดการณ์อีก 1–3 เดือนทันที ใส่จำนวนแล้วได้ใบประมาณราคาที่พิมพ์ บันทึกเป็น PDF หรือส่งทาง LINE ได้

เว็บที่ deploy อยู่: https://thaitay.vercel.app

> **สถานะ:** หน้าเว็บแสดงราคาจริงจาก สนค. พร้อมราคาคาดการณ์ 1–3 เดือนจาก LightGBM ช่วงราคาต่ำ–สูง และป้าย "ราคามีโอกาสเปลี่ยน" สำหรับเดือนหน้าจากความถี่ที่ราคาของวัสดุและหมวดเคยเปลี่ยน ราคาอัปเดตเดือนละครั้งหลัง สนค. ประกาศ โดยค่าเริ่มต้น frontend โหลดไฟล์ JSON ของวัสดุที่สร้างไว้ล่วงหน้า ส่วนระบบบัญชีเรียก Express API ที่เชื่อมต่อ MongoDB ผลการทดลองทั้งหมดอยู่ใน [`ml/DATA_REVIEW.md`](ml/DATA_REVIEW.md) และ notebook [`ml/colab/THAITAY_ML.ipynb`](ml/colab/THAITAY_ML.ipynb)

## ใช้ทำอะไรได้

เพิ่มกราฟราคาย้อนหลัง 6/12/24 เดือน กราฟขึ้น–ลง กราฟเปรียบเทียบฐาน 100 และกราฟต้นทุนแล้ว ดู [รายละเอียดและผลตรวจกราฟ](docs/CHARTS_2026-11-17.md)

- **ค้นหาวัสดุ** ที่ สนค. ยังเก็บราคา 183 รายการ (จากแคตตาล็อก 287 รายการ) ในหมวดงานโครงสร้าง ช่องค้นหาเข้าใจคำหน้างาน เช่น "sd40" เจอ "SD.40", "ปูน", "ไวร์เมช", "เอชบีม", "4 หุน" และ "DB12"
- **ดูราคาและแนวโน้ม** หน้าวัสดุแสดงราคาล่าสุด ราคาคาดการณ์ 1–3 เดือนพร้อมช่วงต่ำ–สูง กราฟย้อนหลัง 12 เดือน และคำแนะนำว่าควรซื้อตอนนี้หรือรอ
- **เหล็กเส้นคิดเป็นเส้นได้** ร้านขายเป็นตันแต่หน้างานนับเป็นเส้น เว็บแปลงให้จากน้ำหนักมาตรฐาน 0.00617 × ศก.² กก./ม.
- **ใบประมาณราคา** ใส่ชื่อโครงการ ลูกค้า จำนวน เงินสำรอง และ VAT 7% แล้วพิมพ์เป็นใบเสนอราคา ดาวน์โหลด CSV หรือส่งลิงก์ทาง LINE ลิงก์เก็บรายการและราคา ณ วันที่ส่งไว้ในตัว จึงไม่ต้องมีเซิร์ฟเวอร์
- **ติดตามวัสดุ** กดดาวแล้ววัสดุนั้นขึ้นที่หน้าแรกพร้อมแนวโน้มราคา 3 เดือน
- **บัญชีผู้ใช้** สมัครและเข้าสู่ระบบด้วยอีเมล เก็บบัญชีใน MongoDB และออกจากระบบผ่าน cookie แบบ httpOnly ดูวิธีตั้งค่าที่ [`backend/README.md`](backend/README.md)
- **มือถือก่อน** แถบล่าง 3 ปุ่ม และไม่มีส่วนไหนล้นจอตั้งแต่ 320 px

## ข้อมูลราคามาจากไหน

รหัสวัสดุใช้รหัสสินค้า 16 หลักของกระทรวงพาณิชย์ (`MAT-…`) ลิงก์แหล่งราคาบนเว็บตั้งไว้ที่ `frontend/src/config/sources.ts`

| แหล่ง | หน่วยงาน | ใช้ทำอะไร |
|---|---|---|
| [ราคาวัสดุก่อสร้าง](https://index.tpso.go.th/construction-material-prices/prices-building-materials) | สนค. กระทรวงพาณิชย์ | ราคาหลักของเว็บ: ราคารายสินค้า รายเดือน ใช้ฝึกโมเดล |
| [ดัชนีราคาวัสดุก่อสร้าง (CMI)](https://www.tpso.go.th/economic-data/construction-materials-price-index) | สนค. | ตรวจแนวโน้มภาพรวม |
| ปัจจัยภายนอก | Yahoo Finance, ปตท. | น้ำมัน Brent แร่เหล็ก ค่าเงินบาท และราคาดีเซล ใช้กับป้าย "ราคามีโอกาสเปลี่ยน" (`ml/fetch_factors.py`) |

ป้ายเดือนหน้าใช้คู่ราคาจริงที่อยู่ติดกันตามปฏิทิน ปรับความถี่รายวัสดุเข้าหาค่าเฉลี่ยหมวดด้วยน้ำหนัก 12 และแจ้งเมื่อคะแนนถึง 0.55 เว็บแสดงป้ายโดยไม่แปลงคะแนนนี้เป็นเปอร์เซ็นต์ ส่วน `change_prob` เป็นผล LightGBM ที่เก็บแยกไว้สำหรับเปรียบเทียบ

## อัปเดตราคารายเดือน

`ml/monthly_update.sh` ทำครบทุกขั้นในคำสั่งเดียว: ดึงราคาใหม่จาก สนค. ดึงปัจจัยภายนอก คำนวณราคาคาดการณ์ ช่วงราคา และป้าย แล้วเขียนไฟล์ JSON ของเว็บ พร้อมสอบคำทายเดือนก่อนกับราคาจริง ตั้งให้รันเองทุกวันที่ 10 ของเดือน แล้วเปิด PR ให้ตรวจก่อน merge เมื่อ merge เข้า `main` แล้ว Vercel deploy เอง วิธีรันเองอยู่ใน [`ml/README.md`](ml/README.md)

## งานที่ยังเหลือ

สถานะตรวจรับงานล่าสุดและข้อจำกัดที่ยังต้องให้เจ้าของระบบดำเนินการอยู่ใน [`docs/HANDOVER_CHECK_2026-11-17.md`](docs/HANDOVER_CHECK_2026-11-17.md)

1. **ปัจจัยภายนอกของป้าย** ถอดถ่านหิน เศษเหล็ก และเหล็กฟิวเจอร์สออกจากเส้นทางรายเดือนแล้ว เพราะยังยืนยันแหล่งและหน่วยไม่ได้ ใช้เฉพาะ 5 ปัจจัยที่อัปเดตได้ ไม่เติมค่าเก่าแทนข้อมูลใหม่ หากจะนำกลับต้องยืนยันแหล่งและทดสอบใหม่ ดู [ผลประเมินป้ายที่แยก calibration/test](docs/SIGNAL_REVISION_2026-11-17.md)
2. **ติดตามความแม่นยำ** เมื่อมีข้อมูลเดือนใหม่ `ml/monthly_update.sh` เรียก `direct_price_model.py` เพื่อสร้างราคาคาดการณ์สำหรับเผยแพร่ และคำนวณ Naive ไว้เทียบกับผลจริงในเดือนถัดไป
3. **API ราคา (ทางเลือก)** ตั้ง `VITE_API_BASE` ตอน build หากต้องการให้หน้าเว็บอ่านราคาจาก FastAPI ใน `ml/serve.py` ซึ่งให้บริการข้อมูลจาก CSV ที่คำนวณไว้แล้ว

### ระบบบัญชีบนเว็บที่ deploy

ถ้า Vercel build เฉพาะ `frontend/` จะเผยแพร่หน้าเว็บและไฟล์ราคาที่มากับเว็บ ระบบสมัครสมาชิกและเข้าสู่ระบบต้องมี `backend/server.js` ทำงานและเชื่อมต่อ MongoDB ด้วย Frontend เรียก `/api/auth` บนโดเมนเว็บเป็นค่าเริ่มต้น จึงต้องส่งต่อเส้นทางนี้ไปยัง backend หรือกำหนด `VITE_AUTH_API_BASE` ตอน build ให้ตรงกับ API ที่ deploy ไว้ ตรวจบริการ Express ได้ด้วย `GET /api/health` บนโดเมนของ backend ซึ่งควรตอบ JSON `{"ok":true}`

### รันระบบบัญชีในเครื่อง

ตั้งค่า MongoDB URI และ secret ใน `backend/.env` ตามตัวอย่างใน [`backend/.env.example`](backend/.env.example) แล้วเปิด backend ด้วย `npm run dev` ในโฟลเดอร์ `backend` จากนั้นเปิด frontend ตามขั้นตอนด้านบน หน้าเข้าสู่ระบบอยู่ที่ `#login` และสมัครสมาชิกที่ `#register` คู่มือ production และ CORS อยู่ใน [`backend/README.md`](backend/README.md)

## รันในเครื่อง

ต้องมี Node.js 22.13 ขึ้นไป

```bash
cd frontend
npm ci
npm run dev        # เปิด URL ที่ Vite แสดง
npm run build      # ตรวจ TypeScript แล้ว build
npm run preview
```

ถ้าหน้าเว็บขาวและ console แจ้ง 404 ของไฟล์ `index-*.js` แปลว่า `base` ไม่ตรงกับ path ที่โฮสต์ ดูตารางหัวข้อ Deploy ใน [`frontend/README.md`](frontend/README.md)
